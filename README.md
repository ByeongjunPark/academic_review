# 학술분과 자문의견서

경남교육청 AI 디지털 교육지원단 학술분과 위원(14명)이 자신이 집필하지 않은 6개 호의 이슈 리포트에 대한 검토 일지를 작성·제출하는 페이지입니다.

- 위원 이름 + 비밀번호로 들어가서 소속·직위, 각 호의 검토일·시간(3시간 단위), `▣ 소제목` / `- 활동내용`을 입력합니다.
- **제출**하면 원본 양식(`자문의견서(이름).hwp`)과 같은 모양의 한글 파일 `자문의견서(이름).hwpx`가 구글 드라이브 폴더에 저장됩니다. 다시 제출하면 기존 파일이 교체됩니다.
- **임시저장**하면 구글 시트 `제출현황` 탭에 저장되어 다른 기기에서도 이어 쓸 수 있습니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `app.js` | 화면 |
| `hwpx.js`, `template/` | 원본 양식을 HWPX로 변환한 템플릿에 내용을 채워 한글 파일 생성 |
| `config.js` | Apps Script 웹 앱 주소 |
| `apps-script/Code.gs` | 백엔드 (비밀번호 확인, 시트 저장, 드라이브 저장) |

## 처음 한 번 설정

1. 구글 시트에 탭 두 개를 준비합니다.
   - `위원` 탭: 1행 제목(집필월, 이름), 2행부터 A열 집필월(예: `7월`), B열 이름
   - `Password` 탭: A1 셀에 비밀번호
   그다음 **확장 프로그램 → Apps Script**를 누릅니다.
2. `Code.gs` 내용을 모두 지우고 `apps-script/Code.gs`를 붙여 넣은 뒤 저장합니다. 위원 이름과 비밀번호는 코드에 없고 시트에서 읽습니다.
3. 함수 목록에서 `setup`을 선택하고 **실행**을 누른 다음 권한을 허용합니다. (시트에 `제출현황` 탭이 생깁니다)
4. **배포 → 새 배포 → 유형: 웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. 나온 웹 앱 URL(`https://script.google.com/macros/s/.../exec`)을 `config.js`의 `GAS_URL`에 넣습니다.
6. GitHub 저장소 **Settings → Pages → Branch: main / (root)** 로 GitHub Pages를 켭니다.

`Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영됩니다(URL은 그대로).
